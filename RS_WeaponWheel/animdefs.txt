// Canvas faces for the cards.
//
// A canvas texture is a blank texture the engine hands ZScript a drawing
// surface for. TexMan.GetCanvas() returns null for anything that is NOT
// declared here, so these lines are not optional setup -- they are the whole
// mechanism.
//
// A FIXED POOL, declared up front, because that is the only way canvas
// textures exist: there is no allocate-on-demand. Twelve is one per ring slot
// with headroom; a thirteenth card falls back to the billboard-composed face
// rather than failing, so a weapon set larger than the pool degrades instead
// of breaking.
//
// 140x100 matches the card's own 3.5 x 2.5 proportions, so artwork painted
// here is not stretched when it lands on the quad. `fit` gives the texture a
// display size, which is what stops it being treated as a 140-map-unit wall.
