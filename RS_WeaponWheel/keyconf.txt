// GUN READOUT PLACEMENT -- console-only on purpose. This is a calibration
// tool for whoever is measuring a weapon set, not a normal-play control, so
// it gets aliases and no default binds. Bind them yourself while placing:
//   bind <key> wr_place        (enter/exit placement mode)
//   bind <key> wr_lock         (lock the free hand's touch point)
//   bind <key> wr_measure      (two-point size measure)
//   bind <key> wr_save         (print the calibration line)
//   bind <key> "wr_nudge 0 1"  (nudge one of the eight axes; see wr_gunhud.zs
//                                for AXIS_F..AXIS_H)
