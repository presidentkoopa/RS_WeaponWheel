// GUN READOUT PLACEMENT -- a calibration tool for whoever is measuring a
// weapon set, not a normal-play control, so it gets NO default binds: none
// of these can fire by accident during a fight because none of them are on
// a key until you put them there.
//
// But bindable FROM THE MENU, not console-only. This mod is used in VR,
// where there is no reachable console at all -- an alias with no key section
// is not "advanced", it is unreachable. The four verbs below are the whole
// workflow; the sixteen nudge aliases stay console/config-only because they
// are eight axes times two directions and would bury the key list, and
// anyone binding all sixteen is editing a config file anyway.
